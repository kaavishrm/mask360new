Did: P2 milestone 1. A manifest v3 extension, provisionally named Conversation Shelf, in products/chat-extension. A content script mounts a side panel in a shadow root that lists the conversations the page already links to on ChatGPT, Claude and Gemini, filters them by title, marks the one open, and refreshes when the site re-renders or navigates. Adapters are defined by URL shape, not CSS classes, and the adapter is chosen by hostname or, on an unknown host, by whichever shape matches the most links. Links inside messages are ignored when the page has a navigation area; duplicates are merged by id. No permissions are requested yet. Icons are rendered from an inline SVG by a script in the repo. A README explains the design and how to load it unpacked.
