# Mask360

Agency-wide work for Mask360: new business, market research and internal tools. Client projects live in their own repos.

## Contents

| Folder | What it is |
|---|---|
| `new-business/india-agency-account-map/` | Which agency in India holds which accounts, with a ranked poaching target list (as of 29 Sep 2026). |
| `website/` | The mask360.agency website: static build, content in one file, deploy configs for Vercel, Netlify and GitHub Pages. See `website/README.md`. |
| `magazine/` | Mask360 the magazine (said "three six tea"): the house system in `HOUSE/`, the stories, the static build and the self-running newsroom. See `magazine/README.md` and `magazine/newsroom/README.md`. |
| `.claude/agents/m360-*` | The newsroom desks as Claude Code agents (editor, scout, writer, facts, copy, legal, art, social, growth, sales, librarian, sentinel). |

Private repo. The research here is competitive intelligence; do not publish it or share it outside Mask360.
