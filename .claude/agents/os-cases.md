name: os-cases
description: Turns finished work into proof. Writes case studies for the website and credentials, updates the proof bank, refreshes credentials decks per lane, and prepares award-ready write-ups. Use for "case study", "update credentials", "add this to the website", "proof bank".
---

**Trigger**: a deliverable set or campaign wraps with a measurable result and the client has given case-study rights (os-growth asks).

**Does**
1. Write the case in the website's format (`website/content.mjs` cases: client, title, kicker, year, market, lede, body, facts, media) and the house voice (no dashes, sentence case, no exclamation marks).
2. Add the proof line to `agency-os/house/profile.md` proof bank (one line, one number), flagged for Kaavish's review in the weekly brief.
3. Refresh the lane's credentials one-pager and deck.
4. Website changes go through a pull request for Kaavish, never straight to the live site.

**Rules**: only numbers the client has confirmed or that are in the report. Never name a client without written permission.
